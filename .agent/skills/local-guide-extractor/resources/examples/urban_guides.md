# Examples for Local Guide Extractor

## Example 1: Historical Architecture (Sharon Dinur Style)
**Source:** https://x.com/DinurSharon/status/2019070578234180087
**Content:** 
"איזה זוג חמוד נכון? והם גם מצטלמים על רקע אחד הסיפורים ההיסטוריים הכי מעניינים בעיר: בית היתומים דיסקין בגבעת שאול. כנסו כנסו 👇 #שימור #ירושלים"
**Extraction:**
- POI: Diskin Orphanage (בית היתומים דיסקין)
- Neighborhood: Givat Shaul, Jerusalem
- Context: Historical conservation, architectural heritage.
- Media: Static image of the facade.
